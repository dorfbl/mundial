# 🏆 הימורי מונדיאל 2026

אפליקציית הימורים לחברים על משחקי המונדיאל 2026.

## דרישות מוקדמות

- [Docker Desktop](https://www.docker.com/products/docker-desktop/) מותקן על המחשב
- חיבור לאינטרנט

## הרצה

```bash
# הפעל הכל בפקודה אחת:
docker compose up --build
```

לאחר מכן פתח בדפדפן: **http://localhost:3000**

## שימוש

### חברים
- נכנסים עם שם משתמש בלבד (ללא סיסמה)
- מהמרים על כל משחק עד 5 דקות לפני הקיקאוף
- ניתן לשנות הימור עד 5 דקות לפני
- ×2 הכפלה: פעם אחת בשלב הבתים + פעם אחת בפלייאוף

### מנהל
- כניסה דרך כפתור "כניסת מנהל" עם הסיסמה
- **סיסמת ברירת מחדל: `admin123`** ← שנה זאת!
- סנכרון משחקים מ-API
- עדכון תוצאות ידני במידת הצורך

## ניקוד

| ניחוש | נקודות |
|-------|--------|
| תוצאה מדויקת | 3 |
| מנצח נכון + הפרש נכון | 2 |
| מנצח נכון בלבד | 1 |
| החמצה | 0 |
| בונוס הארכה (מי ינצח) | +1 |
| הכפלת הימור | ×2 |

## שינוי הגדרות

ערוך את `docker-compose.yml`:
```yaml
environment:
  - FOOTBALL_API_KEY=המפתח_שלך
  - ADMIN_PASSWORD=סיסמה_חזקה_יותר
  - JWT_SECRET=מחרוזת_סודית_אחרת
```

## גיבוי הנתונים

כל הנתונים נשמרים ב-Docker Volume בשם `mundial-data`.

```bash
# גיבוי ידני:
docker run --rm -v mundial2026_mundial-data:/data -v $(pwd):/backup alpine \
  tar czf /backup/mundial-backup.tar.gz /data
```

## הפסקה והמשך

```bash
docker compose stop   # עצור
docker compose start  # המשך
docker compose down   # מחק קונטיינרים (הנתונים נשמרים)
```

## גישה מהטלפון של חברים

1. ודא שהמחשב שלך והטלפון על אותה רשת WiFi
2. מצא את ה-IP של המחשב שלך:
   - Windows: `ipconfig` בטרמינל
   - Mac: `ifconfig | grep inet`
3. חברים יכנסו לכתובת: `http://[ה-IP שלך]:3000`

לדוגמה: `http://192.168.1.100:3000`
